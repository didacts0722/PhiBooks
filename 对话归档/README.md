# 对话归档（无意识层）· 说明

## 架构

- **无意识层**：对话原始记录（`原始/session.jsonl.zstd`，≈33MB）——像语言一样被结构的：未经提炼，但蕴含全部讨论、中间态、被否定的观点、用户原话与裁定。**这是思考的完整上下文。**
- **意识层**：项目沉淀（`notes/` `docs/` `viewpoints/` 等，≈12MB）——提炼后的显式知识：三书笔记（181+83+32 环节）、大纲（核心资产）、观点库 V1-V26、术语主表 550 条、运行简报。

两者关系：**意识层是无意识层的提炼，无意识层是意识层的完整上下文**——回溯「为什么这么定」时查无意识层；使用时查意识层。

## 为什么两个都沉淀

1. **意识层**（12MB）可复用、可对拍、可 git 版本化——这是工作成果
2. **无意识层**（33MB）保留「思考过程」——中间被否定的读法、讨论的弯路、用户裁定的语境——以后重构/复核时，只有意识层不够（它只给结论，不给为什么）

## 文件

```
对话归档/
  原始/session.jsonl.zstd   原始会话（zstd 压缩 JSONL，dsh 格式）
  索引.md                   主题段→产出映射 + 关键裁定（导航）
  README.md                 本文件
```

## 维护

- **归档（独立功能，2026-08-29 与构建解耦）**：
  - `python archive_unconscious.py`——归档当前会话到 `原始/session.jsonl.zstd`
  - `python archive_unconscious.py --all`——归档全部项目会话到 `原始/全部会话/`
  - 内部调用 `工具/同步原始档.js`（读 `$env:DSH_SESSION_JSONL`）
- **解压**：dsh 会话为分块 zstd；安装 zstandard 后按帧解压拼接（或 dsh 自身可读）
- **git**：原始档 33MB 压缩后约 20MB——已纳入 git 跟踪（PhiBooks）；若仓库过大可改 .gitignore + 仅保留索引
