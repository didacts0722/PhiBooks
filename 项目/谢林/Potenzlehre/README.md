## 一、项目定义

- **引擎 = Potenzlehre（潜能学说）**：三潜能（Seinkönnendes / rein Seiendes / Drittes）与三形态（an sich / für sich / bei sich）构成贯穿性三段结构，是神话哲学、启示哲学、自由论文共同的做功骨架。
- **引擎的做功方式**：张力（Spannung）→ 克服（Überwindung）→ 恢复（Wiederherstellung）；否定（Negation）给与力量；终点 = 开端恢复并提升（Wiedereinkehr）。
- **引擎的方向**：a posteriori。绝对者 = 现实性先于一切可能性（Wirklichkeit vor aller Möglichkeit）；原则不是理性推演的前提，而是证明的对象（正哲学）。

## 三、规范（写笔记前必须立住）

1. **不套概念-判断-推论**：谢林引擎 = 三潜能三段 + 张力克服做功 + a posteriori 方向，与黑格尔引擎同构而异质（12 讲 p.786 明确反理性主义：「不是理性是原因，只有因为此精神存在才有理性」）。
2. **反范畴化红线**：三潜能不是康德式范畴（可能性/现实性/必然性）（12 讲 p.783：「Seinkönnende 不是一般的可能性概念，而是 kat' exochên 的 Urmöglichkeit」）。

## 四、术语清单（初步，待逐条提取）

- **Potenz / Potenzen**：潜能（非「力量」）；Potenzenlehre = 潜能学说
- **Seinkönnendes**：能存在者（= 意愿、静息的意志；第一规定）
- **rein Seiendes**：纯粹存在者（第二规定；被置入潜能才能过渡到现实）
- **Drittes / dritte Potenz**：第三者（纯自由；双否定；能存在且能不存在的自由）
- **an sich / für sich / bei sich seiender Geist**：自存 / 为自身存在 / 在自身旁存在的精神（三种形态）
- **actus purissimus**：最纯粹的行动（无张力的神圣存在）
- **Spannung**：张力（三潜能相互排斥的共处状态）
- **theogonischer Prozeß**：神生过程（通过张力恢复神圣存在的活动）
- **demiurgische / kosmische Potenzen**：造物/宇宙潜能（质料因/形式因/目的因）
- **all-einige Geist**：独一全体精神（不是抽象单一，而是活的全体）
- **hypokeimenon / Substrat**：基底（被克服的原初原则）
- **Zeugung = exclusio**：生育 = 排除（否定给与力量）
- **unvordenklich**：不可追忆的（原初存在的特性）
