## 11 讲（p.762–778）· 三重潜能概念的推导

**主线**：从巴门尼德式抽象单一出发，经否定性规定，推出三潜能（Seinkönnendes / rein Seiendes / Drittes），并证明三者是一个三重本质（Ein dreifaches Wesen）的三个规定——**概念推导层**。

| 段落锚 | 主题 | 概念链/演绎链要点 |
|---|---|---|
| 〔p.762〕 | 巴门尼德抽象单一批判 | 存在者之别不在存在本身而在存在的*方式*；「一切同一」的最高概念无用（亚里士多德评 eleatische Einheit 只引起眩晕）；→ Seinkönnendes 作为存在的第一规定（prima determinatione） |
| 〔p.763〕 | 第二规定：rein Seiendes | 直接能存在者经第二规定成为纯粹存在者；potentia pura 的自在性——不自知/不意愿（Unschuld 类比喻）；纯粹潜能天然要成为行动（naturâ suâ Aktus） |
| 〔p.766〕 | Subjekt = Potenz 等同 | 系词分析：A ist B = A 是 B 的 Subjekt；无对立潜能则一切命题同语反复（Pflanze/Materie 例） |
| 〔p.768〕 | 阿拉伯语系词 = Kann | 词源证据：阿拉伯语 Ist 词根即 Kann/Können（homo est sapientem 用宾格）；「无相反潜能则无实义判断」 |
| 〔p.770〕 | 自我返回：非存在 = 魔法 | 词源：Magie = Macht = Möglichkeit = Potenz；能存在者自我返回为 Nichts 反而吸住无限存在者；纯对立 = 最高同一（纯主体不排斥纯客体） |
| 〔p.771〕 | 原初关系决定一切 | Urverhältnis：能存在者作为纯粹存在者的 Subjekt；即便进入现实存在仍是「否定承受者」 |
| 〔p.772〕 | 相对否定与第三者必然性 | 每规定是另一规定的相对否定（单面性）；两者都不是「为其自身而存在」者 → 需要第三者的论证 |
| 〔p.773〕 | 第三者 = 真正自由 | 第三者 = 从单面存在与单面能存在中解放者 = 存在与不存在的自由（zu sein und nicht zu sein erst wirklich Freie）；先为否定表达，正表达待下段 |
| 〔p.774〕 | 三重规定 = 一个三重本质 | 不是 1+1+1，不是三个相互外在的实在；Ein dreifaches Wesen——三个面容（Antlitze） |
| 〔p.775〕 | 不应当存在者 / 应当存在者 | nicht sein Sollende（第一潜能）与 sein Sollende（第三潜能）；恶只在受造物中可能（Böse erst in der Kreatur）；Subjekt = 内在，Prädikat = 外在 |
| 〔p.776〕 | 规定差异非实体差异 | 三规定只是同一者的规定（Differenz der Bestimmung）；第一者只能意愿自身；第三者为不可分主客体 |
| 〔p.777〕 | 绝对者 = 在自身中完成的全体 | 第三者 = 真正终点；对空洞永恒/空洞无限的否定；开端-中-终点互在其中；内有限、外无限 |
| 〔p.778〕 | 精神概念 = 转折点 | **Mit dem Begriff des Geistes tritt nun aber ein vollkommener Wendepunkt ein**（正文止于此） |

**关键引文（待对拍）**：
- 〔p.774〕：„Wir haben nicht drei Wesen, sondern nur Ein dreifaches Wesen, das nur drei Ansichten … Eines, das drei Angesichte, drei Antlitze gleichsam darbietet."
- 〔p.777〕：„…Anfang, Mittel und Ende gegeben, nur daß sie nicht außereinander, sondern ineinander sind."

## 12 讲（p.779–799）· 从三潜能到完全精神的三种形态

**主线**：三潜能只能作为一精神的诸规定（观点反转：将要存在者 = 完全精神）；反范畴化；哲学史批判（自然哲学找回纯 archai）；三潜能归于同一主体 → 完全精神三形态（an sich / für sich / bei sich）→ all-einige Geist。**方法论核心层**。

| 段落锚 | 主题 | 概念链/演绎链要点 |
|---|---|---|
| 〔p.779〕 | 观点反转 | 三概念只是「将要存在者」的必要规定，只能作为一精神的诸规定思考 → 将要存在者 = 完全精神（vollendeter Geist）；不再作为未来存在的可能源泉，首先作为自存者 |
| 〔p.782〕 | 三潜能 = 存在诸原则（archai） | 是存在的原则，**非精神的原则**（„nicht weil sie sind, ist Er, sondern umgekehrt, weil Er ist, sind sie"）；哲学史批判：笛卡尔（物质/思维）、斯宾诺莎（两种实体）、莱布尼茨（表象力）皆非真 archê；近代哲学放弃了探求 |
| 〔p.783〕 | **反范畴化警告** | 三潜能 ≠ 康德范畴（可能性/现实性/必然性）；Seinkönnendes 不是一般可能性概念，而是 kat' exochên 的可能性、Urmöglichkeit、一切生成的第一个根据 |
| 〔p.784〕 | 哲学史批判续 | 康德（摧毁用一般概念中介世界与上帝之路，无意中开辟客观科学之路）；费希特（Ich/Nicht-Ich，但仍是人的自我，非真原则）；**自然哲学首先找回纯 archai**（主客互含、皆不可纯然排除）→ 走出纯主观概念、接纳现实世界 |
| 〔p.785] | **三潜能完整推导 + 归于同一主体** | ① 直接能存在者（= 意愿）→ ② 纯存在者（经 a potentia ad actum，须被置入潜能）→ ③ 第三者（纯自由、双否定）；三潜能只能在一个且同一者中被思考（Ein Subjekt, das die drei ist）→ 只能是精神；经 archôn 的多数性从巴门尼德抽象单一到精神单一 |
| 〔p.786〕 | **反理性主义 + a posteriori** | 未给出精神存在的根据；理性不是原因，只有因为此精神存在才有理性 → 摧毁一切哲学理性主义；此精神无根据、绝对地「因他是」（weil er Ist）；原则只能作为 posterius 证明他（只能 a posteriori）——正哲学的钥匙 |
| 〔p.788〕 | 哲学的原则 = 其对象 = 终点 | 哲学 = 其原则的实现；哲学的力量不在概念开销而在用原则做什么；只有走那条路并展示它的人算证明 |
| 〔p.789〕 | 潜能转为内在规定 | 绝对精神中潜能是 immanent（内转）而非 transitiv（外转）的规定；绝对自由 = 完全 = 自足 = 绝对全（Allheit），且是向内形态的全 |
| 〔p.790〕 | 形态 1：an sich seiender Geist | 自存精神 = 纯自我、绝对不自知、绝对寂静；Aseität 之座；婆罗门呼吸练习类比 |
| 〔p.791〕 | 形态 2：für sich seiender Geist | 为自身存在者 = 作为自身对象、向外、可见者；无自身意志（一方在另一方中忘己）；an sich = 绝对弃绝外在存在（无谓词的主体 = 绝对无自我性） |
| 〔p.792〕 | 形态 3：im an sich für sich seiender | 不能停在第二形态（每形态相对否定另一形态）；第三形态 = 在自存中为自身存在者，不可分地同时是主体与对象（如人的自我意识） |
| 〔p.793〕 | bei sich Sein | 两种规定在「在自身旁的存在」中合一：能离己而存在而不失自存；三形态 a/b/c；完全精神不单是第三形态——**绝对超越**（über alle Arten des Seins） |
| 〔p.795〕 | 运动环节 | 完全精神 = 三者全有；真正终点 = 开端从其否定性解放、客观化；环节：1. 纯自存 2. 离己（在外）3. 返回自身、重获纯自我；只有从自身出来者才能到自身 |
| 〔p.796〕 | 中心/偏心/永恒 | an sich = 纯中心；für sich = 偏心/边缘；第三 = 被设为中心的偏心；无始无终 = 不完善；上帝的无始无终 = 他的开端没有开端、终点没有终点（永恒开端/永恒终点） |
| 〔p.797〕 | nil prius, nil posterius | 三形态非相继构成（如魔术般同时）；完全精神不是三形态之外的第四者——他就是三形态本身，每形态中都是整个精神 |
| 〔p.798〕 | 概念必然性 | 不是因为他是三形态所以完全，而是因为他本然完全所以是三形态（Begriffsnotwendigkeit，非物质必然性）；真正不可毁灭的精神：每部分被分离都会重新成为整体；结论：**all-einige Geist**（独一全体精神） |
| 〔p.799〕 | 活的精神 | 至今只论内在精神；下一步：将来者如何作为可能者显现、精神作为「能存在」的自由——**活的精神**（lebendige Geist），真正「将要存在的」 |

**关键引文（待对拍）**：
- 〔p.782〕：„nicht weil sie sind, ist Er, sondern umgekehrt, weil Er ist, sind sie"（三潜能是存在的原则，非精神的原则）
- 〔p.783〕：„…es ist jene eine, ihresgleichen nicht kennende Möglichkeit, die Möglichkeit kat' exochên, die Urmöglichkeit…"（反范畴化）
- 〔p.785〕：„…diese drei Potenzen des Seins nur in Einem und demselben sich denken lassen … Es ist also Ein Subjekt, das die drei ist … es kann nur Geist sein"（三潜能归于同一主体）
- 〔p.786〕：„…Nur weil ein vollkommener Geist ist, ist eine Vernunft. Dieser selbst aber ist ohne Grund, schlechthin, weil er Ist."（反理性主义）
- 〔p.798〕：„…der vollkommene Geist ist notwendig der all-einige Geist … eine wahre lebendige Allheit"（引擎结论）

## 13 讲（p.801–829）· 从完全精神到创造过程

**主线**：完全精神 = 现实性先于一切可能性；三潜能从「= 他自身」转为「另一存在的可能」（张力 Spannung）；过程（Prozeß）替代 actus purissimus（神生过程）；真正动机 = 创造；三潜能 = 造物/宇宙潜能（质料/形式/目的因）。**Potenz 宇宙化层**。

| 段落锚 | 主题 | 概念链/演绎链要点 |
|---|---|---|
| 〔p.801〕 | 现实性先于可能性 | 完全精神 = 绝对现实性，先于一切可能性；三形态都是「他自身」而非抽象存在方式 |
| 〔p.802〕 | 非绝对/非原初的排除 | 若另一存在的可能性先于他则他非绝对非原初；原创者（original）= 现实先于可能；Potenzen 在他中不是作为潜能而是作为 = 他自身；post actum 才显现另一存在的可能性 |
| 〔p.804〕 | 中保潜能化 | 纯存在者被潜能化 → 必须行动（streben）以恢复纯存在；中保的潜能性（mittelbare Potentialität） |
| 〔p.806〕 | 未预见者的显现 | 普遍潜能化的诱因 = 显现的可能性 = 「未预见者」（Unversehene/Plötzliche）——非意愿的、欢迎的；把精神从不可违背的必然性（Ananke）解放，第一次给予他自己 |
| 〔p.809〕 | 自由接受与否 | 上帝完全自由接受或不接受所显示的存在（spannungslos/gespannt）；In Deo non differunt Esse et quod Est；神性不在 so-Sein 而在「他是他自己」 |
| 〔p.810〕 | 张力的根据 | 张力 = 从自在中走出成为自存的 An-sich（existanenon）；非神亦非全然非神（potentiâ Gott） |
| 〔p.811〕 | 通过对立面 | 上帝通过意志成为在外存在者，但「为了目的」；古老学说：上帝通过对立面实现意图（dia tôn enantiôn） |
| 〔p.812〕 | 从无张力到有张力 | actus purissimus 中形态不可分（旋转 = 不幸福 Unseligkeit）；显现的可能性是脱离旋转的机会 |
| 〔p.816〕 | 过程与创造动机 | 意图 = 把非自设存在转化为自设存在；过程（Prozeß）= 被阻力中断、环节可区分的行动；神生过程（theogonisch）；**真正动机 = 创造（Kreatur）**——没有过程就不能存在者 |
| 〔p.817〕 | 可能性的传布 | 完全精神在第一形态上照见另一存在的可能性；可能性向另两形态传布（Fortpflanzung）；第二形态 = 必须存在的（sein Müssende）= 第二潜能；第三形态 = 被排除的 |
| 〔p.819〕 | 第一次令人信服 | 「一切出自上帝」历来只是情感/辩证强制；我们的发展第一次指出如何从 actus purissimus 到实体化 |
| 〔p.820〕 | 张力中仍是唯一神 | 张力中只有上帝存在；每形态中他是另一个但不是另一个上帝（Mehrere, aber nicht mehrere Götter）；Monotheismus：概念中的 vs 作为教义/现实的（后者 = 潜能相互排斥、真实多数性） |
| 〔p.823〕 | 实体化与内在存在 | 潜能相互排斥却共存于同一处 → 共处非静止；开端原则被实体化（hypostasiert/substantialisiert）；否定给它内在存在、使它成为必须存在者 |
| 〔p.824〕 | 不应当存在者之辨 | 第一潜能 = 「不应当存在者」（nicht sein Sollende）≠「应当不存在者」（Nichtseinsollende）——quod non debet esse vs quod debet non esse；恶只有受造物中才有 |
| 〔p.825〕 | 渐进性 | 创造过程 = 渐进的（sukzessiv）；目的只能在受造物中达成（最后最高者）；在外存在者回归自在 = 来到自身 = 自我意识 |
| 〔p.827〕 | 环节与持存 | 逐步克服；每环节产生形式/形态（Bildungen）——ousiai（实体）；第三潜能 = 每事物的持存（Bestand）之因 |
| 〔p.828〕 | **造物/宇宙潜能** | 每产物 = 三潜能共同作品——demiurgische/kosmische Potenzen；第一 = 质料因（causa ex qua）、第二 = 形式因（causa per quam）、第三 = 目的因（causa finalis, in quam）；hypokeimenon = 被克服的基底；「Angesicht」 |
| 〔p.829〕 | 一神论结论 | 真正一神论（作为系统/教义）只随创造而来；真教义 = 承认自由创造的教义 |

**关键引文（待对拍）**：
- 〔p.801〕：„Der vollkommene Geist ist absolute Wirklichkeit, vor aller Möglichkeit"（引擎总命题）
- 〔p.828〕：„Demnach ist jedes Erzeugte das gemeinschaftliche Werk der drei Potenzen, die sich … als demiurgische, kosmische Potenzen verhalten"（三潜能 = 造物/宇宙潜能）
- 〔p.806〕：„…diese Erscheinung der ersten Möglichkeit … setzt ihn zuerst in Freiheit gegen die Notwendigkeit seines unvordenklichen Seins"（未预见者 = 自由之始）

## 15 讲（p.830–856）· 从创造到三一论

**主线**：出发点 = 上帝在创造中的绝对自由（全一性是自由的基础）；三一性观念非基督教专属；生育 = 排除（exclusio）而非设定；子的本质 = 不求自己的意志的意志；第三潜能 = 贯穿性的（圣灵）；父与子一同实现。**Potenz 落实为位格层**。

| 段落锚 | 主题 | 概念链/演绎链要点 |
|---|---|---|
| 〔p.830〕 | 绝对自由 = 出发点 | 上帝自由地把非存在者提升为存在者；自由只在全一性中有根据；把不应当存在者重新克服回自在的能力 = 自由的基础 |
| 〔p.832〕 | 三一性非基督教专属 | 三一观念是最初者（基督教是它的产物/展开）；新柏拉图「三神」（祖/子/孙 = 世界）是下降谱系、方向相反——对照批判 |
| 〔p.834〕 | 与异教区分 | 子不是自然的直接原则，而是克服/和解自然的潜能（批判把子 = 自然实在） |
| 〔p.835〕 | 莱布尼茨对照 | Leibniz 对苏西尼派：自身反思的精神 = 认识者/被认识者/认识者-被认识者（id, quod intelligit / intelligitur / intelligit et intelligitur）；但只达第一未展开理念，未及发展出的三一性 |
| 〔p.837〕 | 第二神圣位格 | 张力克服后第二潜能回到神性但作为「自身人格」；父 = 把一切置于张力的（penes quem sunt omnia）；父在行动中「生育」子 |
| 〔p.838〕 | 子的永恒性之区分 | 精细区分：1. 原始形态 2. 子「作为子」（a: 仍在父中、只为父；b: 也在父之外） |
| 〔p.839〕 | 哲学思维进程 | 1. 绝对完成精神（纯永恒）2. 可能性显现 → 上帝意识到自己是存在的主人 → 父的概念；子此时仍在父中、已被认识与被爱 |
| 〔p.840〕 | 预知非预生 | 子的永恒性 = 作为被父预知与被爱的子；「真正的生育」只随创造开始（Zeugung = 外在化） |
| 〔p.842〕 | 父 ≠ 生育潜能 | 只有整个上帝是父；potentia existendi = potentia generandi（生育潜能）≠ 父；神生过程的质料（Materie des Gottsetzens） |
| 〔p.843〕 | 生育的时刻 | 创造的开端 = 子的生育开端；父的意志永恒持续（ho patêr mou heôs arti ergazetai——我父作事直到如今）；永恒的生育（始终持续的） |
| 〔p.844〕 | **生育 = 排除** | 生育 = 排除（exclusio）而非设定；否定给予纯存在者以力量（actu 的力量）；从「父的产物」到「子」 |
| 〔p.845〕 | 子的本质 | 约翰 5:26（父在自己有生命，也赐给子）；父的潜能 = 直接能存在，子的潜能 = 间接（经排除）；**子的本质 = 不求自己的意志的意志**（der Wille, der nicht das Seine sucht） |
| 〔p.847〕 | 绝对永恒生育批判 | pro pantôn aiônôn（一切世代之前的生育）批判；gignere est naturae, creare voluntatis（生育属本性、创造属意志）；阿里乌斯论争 |
| 〔p.848〕 | 必要主张 | 1. 子本质上的永恒存在（ho logos theos ên——是神不是那神：theos 非 ho theos）2. 子从永恒被父认识为子（恩典的预旨） |
| 〔p.849〕 | 预知非预生（经文） | 彼前 1:20（proegnôsmenos… phanerôtheis——预知非预生）；保罗：永恒「预旨」（prothesis）非永恒生育 |
