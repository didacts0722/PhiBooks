# 三书关系：引擎在三个介质中的展开（现象学 · 小逻辑 · 法哲学）

> **定位（2026-08-29）**：黑格尔三部核心作品=同一个引擎（die absolute Negativität）在**三个介质**中的展开——**小逻辑=纯范畴层（引擎本身）、现象学=意识层（引擎在自我意识中的显现）、法哲学=制度层（引擎在客观精神/制度中的实现）**。做功方式随介质（概念链+演绎链方法论，术语 2026-08-29 起「推理链」→「演绎链」）。

## 一、三书的介质与做功方式

| 作品 | 介质 | 做功方式 | 引擎定位 | 概念链（整体） |
|---|---|---|---|---|
| **小逻辑**（§1-244） | 纯范畴（思） | 存在论=过渡 / 本质论=反思 / 概念论=发展 | 引擎的自我演示 | 存在=设定 → 本质=判断 → 概念=推论 |
| **现象学**（八章） | 意识（自我意识） | 形态间的扬弃（Gestalt 逐个解构） | 引擎在意识中的显现 | 意识→自我意识→理性→精神→宗教→绝对知识 |
| **法哲学**（§1-360） | 客观精神（制度） | 抽象法=概念 / 道德=判断 / 伦理=推论（重建） | 引擎在制度中的实现 | 抽象法=设定 → 道德=判断 → 伦理=推论 |

**关键**：三书的整体结构**同构**——都是「设定→展开→重建」的完整运转：
- 小逻辑：存在（设定）→本质（判断）→概念（推论）
- 法哲学：抽象法（设定）→道德（判断）→伦理（推论：家庭→市民社会→国家）
- 现象学：意识/自我意识（设定）→理性/精神（判断）→宗教/绝对知识（推论）

## 三、三书的阅读顺序与方法论

1. **阅读顺序**：小逻辑（纯范畴/引擎本身）→ 现象学（意识/引擎显现）→ 法哲学（制度/引擎实现）——**从最抽象到最具体**（或按黑格尔自己的次序：现象学→逻辑学→法哲学=从意识进到纯思再到客观精神）。
2. **方法论统一**：三书都用**概念链+演绎链**分析——形态内环节=概念链（设定→展开→重建），每环节=演绎链一步（每步「推出」非「并列」）。
3. **术语互查**：查任一术语先看主表 works 字段（三书归属），再到对应作品原文核对语境——**同一词三书含义不同层**（如 Anerkennung：现象学=生死斗争，法哲学=制度承认）。
4. **引擎判读**：三书是引擎在三个介质中的展开——**做功方式随介质**：小逻辑（过渡/反思/发展）、现象学（形态扬弃）、法哲学（概念/判断/推论重建）——**读任何一部先问「介质是什么→做功方式是什么」**。
