## 00、前提（隐喻层锁定，防漂移）

- **水** = 精神/概念/自由（黑格尔：精神是实体也是主体）
- **未处理的原水** = 直接性/自然（未概念化的存在）
- **处理后的水** = 经中介的精神（自为的存在）
- **用户用水** = 个体自我意识的实现/被承认
- **污水** = 外化/否定的产物（异化/矛盾）
- **扬弃 = 污水采样分析 → 更新三处（取水层面/供水结构/水质检测办法）**（反馈闭环，非一次性处理：污水是系统的**诊断样本**，系统因污水而升级——Aufhebung 三义：取消[不再是污水]/保存[作为样本进入系统认知]/提升[系统更新]）
- **水质检测** = 系统自我校验/采样（每个环节的知识被检验，不合格即过渡）
- **设备更新** = 系统自我迭代（哲学史=设备更新日志）

### 00.1 水的状态学：概念家族分化（2026-09-04）

隐喻展开到系统层后，「水」必须分化——**不存在「水本身」，只存在处于不同环节的水状态**（概念纪律：别问「水是什么」，问「水在哪个环节」；各状态互相定义=能指差异系统，接术语释义能指/所指条）。

| 水的状态 | 供水系统中 | 隐喻（精神状态） | 对应 |
|---|---|---|---|
| **自然水** | 江河源头，未入系统 | 自在的存在/直接性（绝对者的自然形态） | 逻辑学 Sein/现象学起点 |
| **浑水** | 取水口原水，含杂质待净化 | 未经概念化的经验——**自以为丰富其实贫乏**（感性确定性：「这一个」看似最具体实则最空洞） | 感性确定性 ch1；知性的对象 ch2-3 |
| **净水** | 出厂水，达标可用 | 经概念中介的真知——可用（可被理解/被承认） | 概念论/可用知识 |
| **污水** | 用后水，被污染 | 异化/否定产物——**但=诊断样本（最浊处含最深的诊断信息）** | ch6 异化；扬弃原料（03） |
| 圣水（扩展） | 神庙水塔的水 | 被神话化的净水（宗教把净水说成神赐——水塔神龛的产物） | ch7 表象 |
| 死水/滞水（扩展） | 不流动的存水 | 不扬弃的知性=教条（不动=不净化=坏的） | 知性停滞/坏的无限 |

**关键结构**：
1. **水质光谱=精神形态阶梯**：浑→净=现象学的上升——每个意识形态出场时都是「浑水」（自以为知），经质检线③检验、沉淀出矛盾、过渡到更净的形态。**绝对知识不是「最净的水」，是知道水为什么净的系统知识**=中控室（对循环的自我意识，ch8）。
2. **污水悖论**：最脏的水是系统自我升级的唯一原料——因为它是样本（接 03：扬弃=采样分析→更新）。
3. 原「水=精神」前提细化为：**不同状态的水=精神的不同环节**——单义隐喻在进入系统后让位给状态谱系。

**核心命题**：黑格尔的原创**不是「设计了供水系统」**（部件是前人逐代造的），而是——①把前人散落的部件组装成**含自我监控、自我迭代的闭环**；②**发明了污水处理厂**——而正是「先有处理厂（相信自己能处理一切剩余），才敢设计闭环」：污水厂是整套系统的**可能性条件**，不是管网末端的一件设备。他自己在《哲学史讲演录》里承认踩在巨人肩上（=总设计图纸的维护手册第一章，changelog）。

## 01、黑格尔的水务总设计：四合一

**四合一（纵向卡）**：

- **① 供水网络** — 功能：共时结构——水怎么流到各家。黑格尔对应：逻辑学（管网纯结构：存在论=直管段/本质论=反射回弯管/概念论=目的管段）+ 法哲学（制度层：水塔/街管/入户的制度法规）。
- **② 污水处理（扬弃）** — 功能：污水采样分析 → 更新三处（取水层面/供水结构/质检办法）（反馈闭环）。黑格尔对应：辩证法——矛盾不排掉，收进来当样本分析——分析结果反馈进系统，取水/供水/质检随之更新。
- **③ 水质检测** — 功能：系统自我校验/采样——每段水合格才进下一段；**且质检线自身可被污水反馈升级**（检测办法改善）。黑格尔对应：**现象学 = 整条质检流水线**——每个意识形态都经历「经验」：被检验、发现不合格（此形态的知识不是真知=污水样本）、过渡到下一形态——没有质检线，管网里流什么没人知道。
- **④ 设备更新** — 功能：系统自我迭代——处理工艺随历史升级。黑格尔对应：**哲学史 = 设备更新日志**（每个新哲学=新一代处理设备）；历史哲学=系统迭代史。

**②③④ 实为同一反馈机制的三段**：③质检采样（发现污水）→ ②分析污水样本（诊断缺陷：哪段工艺/结构不行）→ ④据此更新（取水层面/供水结构/质检办法——含质检线自身的自我升级）→ 新工艺运行又产生新污水（新矛盾）→ 再采样再分析再更新——**扬弃=系统从自己的污水中学习（连「怎么学」都学），螺旋上升**。质检线不采样，处理厂无样本可析；处理厂不反馈，更新机制无源可依——三者缺一，扬弃就退化成「把污水倒掉」。

**四者合起来才叫「黑格尔体系」**：管网（逻辑/法）给结构，扬弃闭环（辩证+质检+更新）给动力与时间性。缺任何一件系统都是死的：有管网无质检=水到户但不知脏没脏；有处理厂无反馈=工艺永远停在 1807 年。**这解释了他为什么承认前人**：每次更新都记录在案——他的原创=把前人造的部件接进一个会自检、会从自身污水中学习的闭环。

### 02.1 水塔专条：区域化容量存储 + 压力存储（2026-09-04 确认）

- **容量存储（储水）** = 市民社会的需求体系：按需取用的蓄水池——伦理实体把个体的欲望/需求储起来、按需供给（家庭→市民社会→国家=逐级增大的储水单元）；
- **压力存储（稳压）** = ch7 宗教：给悬空的个体自我意识（ch4 后半的斯多亚/怀疑/苦恼）供给「被承托」的势能——无条件承认（V26）就是稳定水压；水塔不掉压，苦恼意识才不会崩；
- 神龛=宗教的自我理解（把水塔的稳压功能神话为神的恩典）——直到 ch8 绝对知识：看穿压力来自水塔结构本身，不是水神。

### 02.2 历史化注：部件表是现代系统的共时结构

部件表（入户管/龙头/集中水厂/污水厂）是黑格尔**现代**系统的共时结构——「入户」「集中净化」「污水处理」都是历史产物，不是供水自古以来的形态。读前史（04）时必须放下这些现代部件，看古人实际造了什么（2026-09-04 用户修正：古希腊没有「自来水入户」这种产品形态）。

### 02.3 供水模式形态史（末端形态 = 承认形态）

- **古希腊** — 供水形态：公共水池/喷泉/澡堂/蓄水池。水到**场所**（广场/神庙/浴场），不到户。承认形态：城邦公共性（个体淹没在伦理实体中——ch6 早期伦理直接性）——**但公共=自由人的公共，奴隶不在供水对象内（见 02.5）**。
- **罗马** — 供水形态：输水道（aqueduct）+ 公共浴场 + 贵族私接。水到：城市公共为主，少数私户。承认形态：私接萌芽=个体性原则的雏形。
- **中世纪** — 供水形态：工程断裂（输水道毁→城市回井/河）；修道院=唯一微缩系统（封闭自用）。水到：水=恩典，教会垄断分配（圣水仪式化）——城市居民喝回浑水却以为仍是净水。承认形态：教会的恩典等级（神权中介：个体经教会得水=经教会得救——俗人被排出供水对象，见 04.5）。
- **德国观念论** — 供水形态：**入户概念诞生（概念转折，非工程）**——水第一次被构想为到**户**（个体主体）而非场所。水到：康德=入户立法（先验资格：人人先天可接入，范畴=入户管规格对所有人一样）；费希特=入户激进完成（户=源，无需管网）。承认形态：承认锚回主体自身（先验自我/自我——不再靠城邦或教会中介）；见 04 前史表康德/费希特条目。
- **现代（工业实现）** — 供水形态：自来水入户（工程实现观念论的入户概念）。水到：**每户**——普遍化。承认形态：承认普遍化到个体（§124 主观自由=现代判据；§209 人因其为人而有效=康德先验资格的世俗化落地）。

**供水末端形态史=承认形态史**：水到公共场所=承认还是城邦公共性的（希腊伦理=实体直接性）；水到每户=承认普遍化到个体。**入户=两步：德国观念论给概念（康德立法/费希特激进完成——合法性锚回主体），工业时代给工程（自来水实现概念）**——黑格尔的「人人有龙头」是把观念论的入户概念接进制度管网（入户合法性+制度结构的总装），不是发明入户——再次证明他站在前人肩上：取水/公共供水是希腊遗产，入户概念是观念论遗产，入户工程是现代实现。

### 02.4 净水能力形态史（水厂是被功能性替代的）

**古代净水能力是大问题——没有集中净化厂，「水厂」的功能被三样东西分散承担**：
1. **选取净水口（选址=源头净化）**：净化靠选水源——取上游/圣泉，不取下游脏水；圣泉崇拜/神谕选址（德尔斐/阿斯克勒庇俄斯）=选址标准的神圣化形式；
2. **水沉淀（时间/重力=物理净化）**：静置让泥沙下沉——净化靠等；
3. **水池功能性（容器=储存兼沉淀）**：蓄水池（cistern）同时承担存储+沉淀。

**古人不是「不会净化」，是净化分散在选址、时间、容器里——集中水厂是近代概念**（2026-09-04 用户修正）。这修正 04 表里柏拉图的定位：他设计的不是「集中净化工艺」（那时代没有），是**净水标准/净水口选取判据**——理念论=「什么才是真正的水」=选水哲学：把圣泉的神圣标准**理性化**为理念标准。他的「水厂」=标准，不是工艺。

### 02.5 供水对象史：谁有资格用水（社会分层，2026-09-04 用户补充）

**古代「公共供水」的公共=自由人的公共**——奴隶制下：**奴隶肯定没有水，奴隶与主人不能同澡堂**。共浴隔离不是卫生问题，是**承认的空间装置**：澡堂不是洗身子的地方，是承认资格的空间——谁有资格进入热水、与谁同浴=谁被承认为人。

**奴隶的悖论位置**：他**取水劳动**（挑水/烧水/服侍主人浴）却在供水对象之外——劳动生产水，水被主人享用，劳动者被排除在享用外=**异化的原始形态**（V21：可承认性破坏——取水不带来用水权）。直接接 ch4 主奴：奴隶经劳动获 Bildung 却不被主人承认——**供水隐喻：奴隶取水但不被供水**。

**宗教加剧排斥**：神庙圣泉只给洁净者/有仪式资格者——供水资格的神圣化（奴隶/不洁者碰不得圣水=神龛的排斥面）。

**供水对象史=承认对象史**：

- **古代** — 供水对象：自由人/公民（奴隶=会说话的工具 instrumentum vocale，不在对象内）。排斥的合法性：制度性排除=合法（等级制）。
- **罗马** — 供水对象：公共浴场仍有等级（富人私浴/奴隶服务）。排斥的合法性：等级内嵌。
- **现代** — 供水对象：**每个人**（§209：人因其为人而有效）。排斥的合法性：排斥失去合法性——**现代仍有人没水=系统故障/压迫，不是制度设计**（接 §244 贱民=被排出供水对象者；承认学说流魂=取水劳动+不被供水的流魂版）。

**收口一刀**：主人有水但不会取水——水对主人=现成享受（用完就没了），对奴隶=劳动对象（取水过程=塑造=Bildung）——主人的水是死的享受，奴隶的水是活的劳动。ch4 判读：劳动塑造自我，享受空洞化。

## 03、污水处理厂 = 前提性发明（轴心）

**哲学史 = 每个前人留下处理不了的剩余（矛盾）**，前人的处理方式=排除/拒绝/悬置（把处理不了的倒掉=排污水）：

| 前人 | 留下的剩余 | 处理方式 |
|---|---|---|
| 巴门尼德 | 变化/生成怎么办 | 拒绝（净水主义——只要纯水，宁可不动） |
| 柏拉图 | 理念与现实之间的鸿沟 | 无法施工（净水标准有了，配送/施工无解） |
| 亚里士多德 | 第一推动者（动力从哪来） | 悬置（不动的动者=泵的原动力假设） |
| 康德 | 物自体（入户立法已完成：先验资格=人人先天可接入） | 排出系统外（原水不可达，只有管网里的现象水） |
| 费希特 | 自我与非我的对立（入户激进完成：户=源，无需管网） | 每户自稳压，户与户之间无解 |

**黑格尔的发明 = 「污水样本反馈机制」（扬弃的完整定义，2026-09-04 用户修正）**：污水不是要被处理掉的废料，是**系统的诊断样本**——矛盾不排掉，收进来**采样分析**：这污水暴露了系统哪段工艺/结构的缺陷（哪里的水不该脏/哪段净化没到位/哪个环节的设计产生了这种废水）→ **分析结果反馈到三处**：①更新取水层面（水源检测判据/取水点选取=源头净化升级——污水若暴露水源问题则改前端）②更新供水结构（管网/水塔/街管设计——让产生这种污水的环节不再产生它）③更新水质检测办法（质检线③的自我升级——旧的检测方法测不出的问题，先升级检测本身，否则问题永不可见）→ 系统升级 → 新工艺运行产生**新污水**（新矛盾）→ 再采样再分析再更新。**扬弃=通过分析污水样本更新取水/供水/质检三个层面**——系统从自己的污水中学习（连「怎么学」都学），螺旋上升，不是一次性把水弄干净就完事。

**前人的扬弃观 = 排掉污水（不采样、不学习）**——所以前人的系统永远停在原工艺：矛盾来了倒掉，缺陷永远不被看见、不被修复。黑格尔的处理厂之所以是前提性发明，正在于它把「污水」从**需要清除的废料**改写成**系统自我认知的数据**——有处理厂（会采样会反馈），系统才敢设计成闭环：**任何缺陷都会变成样本回来改进系统本身**。

**关键推论**：**先有污水处理厂（相信自己能处理一切剩余），才有闭环设计（敢画无排放系统）**——污水厂是整套系统的**可能性条件**。没有它，闭环图纸画出来也只是把污水排到下游（前人就是这么干的）。

**污水链（被谁承接）**：
- **马克思承接**：接住黑格尔处理不完的剩余——**无产阶级/贱民 = 市民社会的污水（§244 贱民，本地锚：承认失败/流魂的精神层剩余）**。马克思说黑格尔的污水厂工艺不行（无产阶级还在排污口），要换处理工艺（革命）——但马克思自己的剩余也没处理完（革命后的污水谁管？）——他留下：接管≠重建（接管后谁调阀？推论失速）。
- **齐泽克/拉康 = 实在界浓缩液**：符号化原则上处理不掉——「没有处理不了的」被质疑（我们的分歧点原样保留：黑格尔说无不可扬弃只有尚未扬弃，拉康说有原则上抗拒的浓缩液）。
- 现代市民社会 = 水压永远差一点（V28 绩效/小 a 机制）：水塔被资本接管后，阀门设计成差一点——不是没水，是水压被调过（接现代哲学地图册的收口）。

## 04、前史：水务设计史（设备更新日志·第一章）

**每个前人都不是「不完整的黑格尔」，而是黑格尔系统的部件供应商**——黑格尔自己承认这点（哲学史讲演录）：部件逐代补齐，他是总集成师（纵向人物卡）。

- **泰勒斯** —— 看见水源：第一个看见水的人——不建设施（万物皆水=自己就是水源），水源派始祖。*留下的剩余：水看见了，怎么送到家没人管*
- **赫拉克利特** —— 水自己会流派：万物流变=水本来就该流——反对管道（流变无需系统）。*留下的剩余：流变=污水也在流（好坏不分）*
- **巴门尼德** —— 净水派：要纯水：存在=纯净不动，生成=污染——宁可不输送也不要杂质（供水问题被还原成净化问题）。*留下的剩余：变化/生成怎么办（他拒绝=排出）*
- **苏格拉底** —— 浑水揭穿者 + 净水教导者：发现城邦的人都在**用浑水（意见 doxa），并且用浑水冒充净水**（智者把修辞当知识卖：「人是万物的尺度」=浑水也能自称净水）。他的提问（elenchus）=**检测装置**：让对话者发现自己以为的净水其实是浑水（承认无知=从浑水里醒来的第一步）——但他不止于揭穿：他**教导民众——只有净水才是你真正需要的**（知识=德性，真知存在且值得追求；苏格拉底不是怀疑派，他知道有净水，只是人们还没喝到）。**序列位置=需求唤醒者**：先有「要净水」的需求觉醒（苏格拉底）→「什么算净水」的标准（柏拉图）→「把净水送到家」的施工（亚里士多德）。*留下的剩余：只检测/教导个体，不建系统（水厂/管网留给柏拉图）*
- **柏拉图** —— 净水标准设计者（不是集中水厂）：古代无集中净化厂（净化=净水口选址+沉淀+水池功能性替代，02.4）——他提供的是**选水判据**：理念论=「什么才是真正的水」的纯度标准（把圣泉神圣标准理性化为理念标准=净水哲学）；理想国=供水网络建立的组织方法论（哲人王=总工/护卫者=守厂/生产者=取水劳动；教育=技师培训）。**供水形态=公共澡堂/水池：理想国废除家庭与私有财产→无「户」可入→水只到公共场所**（无入户管不是缺陷，是他的社会没有「户」这个末端）。*留下的剩余：理念与现实之间的鸿沟（标准有了，配送/施工无解——分有/摹仿/回忆=一生反复试造转换器）*
- **亚里士多德** —— 工程思维入场：哲学作为科学=把净水标准（柏拉图）扩展成**可施工的完整供水系统**：四因=工程四问（质料=水/形式=管形/动力=泵/目的=入户）；工具论=施工规范与验收标准——蓝图第一次有了施工可行性。**转折：他有 oikos（家政学）——第一个系统讲「户」的哲学家**（oikos=生产单位，非现代消费私户）——供水开始有「入户」萌芽（从公共澡堂向户延伸的第一步）。*留下的剩余：第一推动者（泵的原动力悬置）*
- **第欧根尼/斯多亚/犬儒** —— 井派雏形：木桶接河水，够喝即可（不动心=不求管网）。*留下的剩余：拒绝系统（个体自足=井派源头）*
- **中世纪（奥古斯丁/修道院/阿奎那）** —— 圣水垄断（见 04.5）：工程断裂（罗马输水道毁→城市回井/河）；修道院=唯一微缩系统（封闭自用）；教会垄断净水标准：圣水=净水神学化——净化靠仪式（洗礼）不靠检验，**质检线③被神父宣告取代**；阿奎那=把亚氏图纸翻译成神学施工规范（哲学=神学婢女）。*留下的剩余：俗人被排出供水对象（净水=修士/教会特权）——留给宗教改革与近代去质疑*
- **笛卡尔** —— 从零验水：怀疑一切管道（包括教会给的「圣水」——你怎么知道那是净水？），确认至少有一滴（cogito）是真的；但只有一滴没有系统（身心二元=水塔和管道断了）。*留下的剩余：一滴水怎么变成管网（他答不了）*
- **斯宾诺莎** —— 全城皆水源：泛神论：实体=水=神——没有取水口（一切皆水，无需输送）。*留下的剩余：水到处是=也就没有「送水」这回事（无中介）*
- **莱布尼茨** —— 分散式供水：单子=每户独立微型水厂，无管网（靠神预定和谐同步）。*留下的剩余：户与户之间只靠神同步（无真实连接）*
- **洛克/经验论** —— 只验收不设计：只信入户的水（龙头流出什么就是什么），怀疑图纸（理性=白板=空水塔）。*留下的剩余：经验不可靠（水龙头也会坏）*

### 04.5 中世纪：净水断裂与圣水垄断（宗教在此出场，2026-09-04）

> 链路从罗马工程直接跳到笛卡尔是断裂——中世纪不是空档，是**宗教接管供水系统的时代**：工程传统断裂，净水被神学化垄断。

1. **净水能力断裂（工程倒退）**：罗马输水道衰败/毁坏（蛮族入侵+失修）→城市回到井/河取水——水质从净水**退回浑水**（罗马水塔塌了没人会修——工程知识失传）。但人们仍以为自己在用净水——**浑水冒充净水的第一次大规模制度化：不是智者卖（希腊），是教会赐（中世纪）**——水质合格由信仰保证，不由检验。
2. **修道院=微缩保留区**：唯一维持工程传统的地方（本笃会水渠/蓄水池——罗马工程在修道院复活）——但**封闭自用**：供水对象=修士，不是城邦——净水成为特权（接 02.5 供水对象史：排除范围从奴隶扩大到俗人）。
3. **圣水=净水的神学化垄断**：水质标准从理性/工程（柏拉图理念/亚氏四因）变成**神学教义**——什么是好水=教会说了算；净化靠**仪式**（洗礼=水的净化仪式化）不靠检验——**质检线③被仪式取代**：水的合格由神父宣告，不由检测判定——水塔神龛从「解释系统」变成「管理系统」（神权管水厂；接 02.1 神龛专条——中世纪的宗教不是水塔上的装饰，是水厂的主管）。
4. **阿奎那=图纸翻译官**：把亚里士多德的工程图纸翻译成神学施工规范（哲学=神学婢女=工程队归水厂神父管；五路证明=给供水系统装神学地基）——图纸施工权归教会——工程被审查后用于建「圣水厂」。
5. **宗教改革=圣水垄断的第一道裂口**（预埋近代）：路德「人人可直接读经」=人人可直接取水？——把净水标准从教会还给个人/理性——为笛卡尔「从零验水」和启蒙自来水铺路。**笛卡尔不是凭空开始，是对圣水垄断的怀疑：你怎么知道教会给的是净水？**
6. **教堂=澡堂的继承者（2026-09-04 用户观察：区别不大）**：中世纪没有入户水——水仍在**场所**（洗礼池/圣水盆），末端形态未变（场所化供水延续）。变的是一组转移：净化对象**身体→灵魂**（水洗→圣水仪式）、资格标准**自由人→信徒**（奴隶不能进澡堂/未受洗者不能领圣水——排除逻辑一致，标准从身份换信仰）、承认的锚**现世城邦→彼岸教会**（澡堂=现世承托/公民身份日常确认；教堂=彼岸承托/救赎身份确认——ch6 精神到 ch7 宗教的供水隐喻版）。**修正 04.5 隐含偏差**：中世纪不是「净水消失退回浑水」——净水被**收进教堂垄断**：市民喝井水是浑水，但真净水在教堂（圣水）——净化从**日常**（澡堂/身体/每天）**收缩为仪式**（教堂/灵魂/礼拜日），净水从工程产品变成仪式产品。

**收口**：中世纪=ch7 宗教的历史实体化统治期——神权管水厂。从圣水垄断到自来水健忘（05），中间只隔一次启蒙：启蒙的自来水是对中世纪圣水垄断的反叛（理性普遍化取代神权分配），反叛成功后又忘了自己的系统历史。

## 05、用户视角：自来水健忘症（2026-09-04）

> 前四节全是**设计者视角**（系统怎么被造出来）；本节翻到**用户视角**——现代用户面对这套系统时发生了什么。

### 1. 系统本质 = 存量-流量系统（stock-flow）

- **水塔/储水池 = 存量**（存水）；**管道 = 流量**（用水）。古代的核心是**存水**——存量管理决定一切：存多少由用水习惯决定（挑水频率/浴场时间/旱季储备）。
- **水塔是时代性产物，不是永恒部件**：在无管道/间歇供水的时代，存量是命脉——它服务的是「存水+用水+生活习惯」这套生活模式，不是普遍的工程常数。
- **存量-流量 = 潜能-实现（尚且-已经是）**：存水=潜能（尚且在储），用水=实现（已经是用）——亚里士多德 dunamis-energeia 的供水版。用水习惯（何时用多少）=伦理的日常形态（Sittlichkeit=习俗——用水习惯是承认的日常化）。

### 2. 自来水（启蒙）时代 = 遗忘装置

- 用户打开龙头就有水——**流量即得，存量系统（水塔/水厂/历史）从视野消失**——用户只面对净水的直接性，不知道净水是被中介的产物。**净水的直接性 = 忘记中介的直接性**。
- **自来水健忘症 = 物化**：把历史性、社会性产物（供水系统=承认结构）当成自然事实（打开就有）。接齐泽克：意识形态不在你对水的观念里，在**你每天打开龙头的实践里**——每次开水=重复一次遗忘。
- 接 V23：承认被制度化生产（水厂净化=承认生产）但用户只见结果（净水=绩效/履历），忘记系统——**用户是流量消费者，不是系统知情者**。

### 3. 黑格尔哲学 = 反健忘症装置

- 现象学（质检线③）的全部工作=**让中介显形**——让用户记起这杯净水经过了取水口/沉淀/管网/水塔（=让承认的尚且被记起）；哲学史（④）=提醒系统有历史。
- **启蒙=自来水时代：许诺「打开就有」（光明/知识/自由），却也继承了遗忘**——阿多诺/霍克海默：启蒙变成神话=自来水系统本身被自然化（水厂成了新的圣水，接 00.1 圣水扩展格）。

### 4. 收口（接姿态地图册）

**阀门可重调的前提是记起阀门存在**。自来水健忘症患者不觉得有阀门（打开就有水），所以从不想重调；哲学（中控室视角）=让用户记起存量系统、记起水是被送来的——**记起尚且，才谈得上重调**（尚且/重建：不是认了差一点的水压过日子）。
