# 项目全流程（黑格尔哲学引擎 · 注释版）

> 现象学项目沉淀的完整工作流，供后续作品（小逻辑、法哲学等）直接复用。详细规范见 `docs/注释规范.md`。

## 一、文献获取（模块①）

1. **下载**：`download_philosophers.py`（按哲学家爬 zeno.org，4 线程、断点续传）。
2. **提取**：`extract_zeno.py`（iso-8859-1 解码、正文白名单、页码锚点入库）/ `extract_all.py`（全量）。
   - 白名单：无 class + `zenoPLm\d+n\d+`（普查确认后扩展，`survey_pclasses.py`）。
3. **清单**：`rebuild_manifest.py`（按磁盘实况统计页数）→ `gen_文献清单.py` → `docs/文献清单.md`。
4. **原文核验**（信样本，不凭记忆）：§/章节覆盖范围、页码锚点、段落数、提取质量。

## 二、笔记构建（核心闭环）

1. **提目录**：从提取数据的结构标题生成章节/小节骨架 → `docs/<作品>_大纲.md`。
2. **切块**：按「环节」切原文，每环节 = [标题, 页码, 德文引文, 原解读, supplements?, diagram?, paras?]。
3. **写笔记**（引擎框架）：概念-判断-推论三段；做功方式随介质（存在论=过渡/本质论=反思/概念论=发展）；诊断从形态内部推出。
4. **引文锚点**：每环节一条德文引文，〔段 N〕链接跳回原文段（原书页码在悬停）。
5. **对拍校验**：`build_<作品>.py`（自动对拍）+ `verify_<作品>.py`（引文命中/标签配平/段落计数/观点库/术语校验）。

## 三、讨论与补充

1. **讨论分段索引**：`docs/讨论分段索引.md`（主题→环节 定位表）。
2. **补充机制**：环节 supplements（追加不覆盖、默认展开、口语化）；⚙️ 引擎标注/🔑 关键概念。
3. **二手文献三纪律**：不采用其译文（宁可不翻译）｜删去其对其他哲学家的论战｜事实类大胆采纳、分析类过引擎。

## 四、术语体系

1. **哲学家术语主表**：`viewpoints/glossary/<哲学家>.json`（每术语带 works 标签、canonical 译法）。
2. **选词四标准**：①引擎相关核心概念 ②逻辑推演关键词 ③德语形态（Sein/Seiende、形容词名词化）④历史文化强相关。
3. **术语条**：术语表 × 该段德文引文 双重过滤，上限 10，首次出现 §。
4. **底部通览**：完整主表两列通栏（页面底部）。
5. **跨作品一致性**：`validate_glossary.py` 查同一德文词跨作品译法冲突。

## 五、阅读辅助（未引段）

1. `dump_uncited.py` 导出未引段 → 子代理分章/分片产出（首尾句硬译分块 + 障碍词）→ `merge_rh.py` 合并 + **de 逐字命中校验**（不过不收）。
2. 翻译卡在笔记侧（右栏 .pair 并排、sticky），原文列保持纯德文。

## 六、引擎标注与结构

1. ⚙️ die absolute Negativität（推动前进的关键处 + 尚待消解环节：坏的无限/片面否定）。
2. 🔑 关键概念（如 Bildung 双向塑造）。
3. **命题链**（章节收尾）：设定命题 → 展开矛盾 → 重建命题 → 过渡。
4. **实体即主体**：以绝对者为主体的阶段划分（全书级）。

## 七、UI 与验证

1. **UI 规范**：双栏（原文|笔记）、段落化（page 显示层废弃）、笔记吸顶、锚段并排（.pair）、阅读辅助右栏、目录 spy（块为主定位）、底部术语通览、移动端单栏。
2. **验证链五件套**：引文对拍 / 标签配平 / 段落-引文计数 / 观点库校验 / 术语主表校验。

## 八、文档沉淀

- `docs/注释规范.md`（全量规范）、`docs/运行简报.md`（每轮质量+反推+待办）、`docs/对话档案.md`（跨轮传递物）、`docs/<作品>_大纲.md`、`docs/<作品>_实际目录.md`。

## 九、工作节奏

1. 分阶段、逐章闭环：抓原文→提目录→写笔记→引文锚点→对拍校验→下一章。
2. 每轮结束：更新运行简报（质量指标+反推结论+下一轮待办）。
3. 子代理产线：重活（阅读辅助、二手清点）并行派发，父代理做质检与合并。
