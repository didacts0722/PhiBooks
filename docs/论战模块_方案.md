# 论战模块方案（Polemik-Modul）——用论战检验方法论

> **定位（2026-08-29 用户提出）**：日后建立论战模块——**从论战的角度检验我们的方法论**。目的只有一个：**使我们的解读尽可能贴合文本**。论战不是学术吵架，是检验工具：拿有影响力的解读与我们对阵，看谁的读法能被德文原文逐字支持。
> **状态**：方案（日后实施，本轮不建模块）

---

## 一、模块的检验逻辑

```
对手论点（Pippin/Kojève/Lukács 等）
    ↓ 提取关键分歧点（2-3 个/人）
我们的解读（引擎框架：概念链+演绎链）
    ↓ 文本证据对决（德文原文锚，逐字对拍）
检验结论：谁更贴合文本？我们的解读被文本校正了什么？
```

**检验标准（三条，权重排序）**：
1. **文本证据权重 > 理论立场**：谁能用原文逐字支持自己的读法（对拍是硬标准）——「我认为黑格尔想说」不算，`*原文*`才算
2. **系统性**：谁的解读能覆盖全书（不只选段）——Kojève 把主奴辩证放大成全书核心=选段放大；我们的引擎框架=跨三书一致
3. **自洽性**：概念链是否每一步「推出」（演绎链纪律）——对手的读法在文本里有没有断裂点

**预期收益**：
- 我们的解读被对手的问题逼着回到原文（防止框架自嗨——框架也可能遮蔽文本，论战是纠偏器）
- 对手的误读=接受史/误读史样本（对接大纲第八节：误读=研究对象）
- 方法论经受外部检验（引擎框架的边界在哪里——论战会暴露）

## 二、模块结构

```
docs/论战/
  README.md         模块规则（对手选择/检验标准/文本证据纪律/更新日志）
  01_Pippin_非形而上学读法.md
  02_Kojève_人类学读法.md
  03_Lukács_马克思主义读法.md
  04_Pinkard_社会性读法.md
  ...（按需追加）
```

**每篇固定结构**：
1. **对手论点**：立场概述（2-3 个核心主张）——**来源标注**（本地文献库有原文/无原文待补）
2. **关键分歧点**：对手 vs 我们的解读，分歧在哪（2-3 点，落到具体文本位置）
3. **文本证据对决**：同一段德文原文，双方读法对照（引文逐字，对拍）
4. **检验结论**：谁更贴合文本；我们的解读被校正了什么（或对手的合理处被吸收）

## 三、纪律（延续项目红线）

1. **对手文本=本地文献库原则**（广采例外纪律不适用于论战——论战引用对手原句必须逐字）：对手著作本地库大多没有（Pippin《Hegel's Idealism》等）——初期论战=「立场概述（标注：无本地原文，待补）+我们的回应」；日后补库后可逐字对拍对手引文。
2. **德文原文优先**：裁决权在德文原文，不在二手解读——对手的英译/转述不增不减。
3. **不追求「赢」**：论战是检验工具，结论可能是「对手这里有道理，我们吸收」——吸收后更新观点库（V#）或笔记。
4. **文本内批判保留**（二手三纪律第 2 条的延伸）：黑格尔文本内的批判（批康德/费希特/孟德斯鸠）保留；对对手的批判必须落到文本证据。
5. **每次论战产出一份「文本贴合度报告」**：我们的解读在哪些点上被文本支持、哪些点需要修正——写入运行简报。

## 四、第一批论战对象（按优先级）

1. **Pippin（非形而上学读法）**：他把黑格尔裁剪进分析哲学的先验论证——检验：非形而上学读法能否覆盖《逻辑学》的「无预设开端」（§1 Sein）？引擎框架的「概念链」是不是 Pippin 说的「先验论证」？分歧点：形而上学与否=文本说了算还是立场说了算。
2. **Kojève（人类学读法）**：主奴辩证=全书核心+历史终结——检验：主奴辩证在现象学全书中的地位（181 环节中 ch4 只是 10 环节之一）；「历史终结」的文本支持（ch8 绝对知识 vs 法哲学 §341 世界历史=世界法庭——历史继续）。分歧点：选段放大 vs 系统性。
3. **Lukács（马克思主义读法）**：劳动/承认=历史唯物主义前史——检验：承认理论（V23）与 Lukács 的劳动读法的亲缘与界限；辩证法=方法论 vs 历史规律。
4. **Pinkard（社会性读法）**：规范性/社会性——检验：承认理论的社会性维度（V23 承认的制度化）与 Pinkard 的差别（我们=实体性结构，非规范理想）。
5. **哈贝马斯（现代性读法）**：黑格尔=现代性问题的开端——检验：挪用 vs 注释的边界（他是借黑格尔说自己的话）。

## 五、与现有模块的对接

- **大纲第八节**（国家学说的历史命运/挪用史）：论战=同一思路的深化——误读史=研究对象

- **观点库**：论战吸收的合理处沉淀为 V#；被驳倒的对手立场记入「误读史」样本
- **运行简报**：每场论战结束更新「文本贴合度报告」
