## 1. 术语纪律（编写时硬约束）

- **禁「正反合」**（康德/费希特用语，黑格尔文本不用）→ 一律用：**概念-判断-推论**；或 **抽象知性（abstrakter Verstand）→ 辩证理性（dialektische Vernunft）→ 思辨理性（spekulative Vernunft）**。
- **禁「知—行」框架**（2026-08-26 停用）→ 现象学各形态改由「引擎诊断」处理（见 §3.5）。
- **dialektisch = 解构的力**（否定、彻底怀疑、动荡）；**spekulativ = 重建的力**（已扬弃、接受自身否定整体的肯定结果）。二者是功能分工，不是先后步骤。
- 引擎术语表：概念-判断-推论 / 过渡（Übergehen）-反思（Reflexion）-发展（Entfaltung）/ 扬弃（Aufheben）/ 表象（Vorstellung）-概念（Begriff）/ 场域 / 环节 / 原始数据 / 生成性-统摄性。
- 引文必须有文本依据；§ 编号标注，细粒度 § 编写时核对原文。

## 3. 内容层级（每类节点的内容模板）

### 3.1 总纲·引擎工作手册（修正版）

每节结构：
- **引擎的三段循环**：概念（范畴的直接肯定形态）→ 判断（自我否定、分裂、外化）→ 推论（对立统一、回归）。注明：**这不是正反合**，而是概念自身的生命运动（"概念在自身中设定对立，并在对立中保持自身"；否定之否定）。
- **三大做功方式**：存在论=过渡（范畴直接消失为另一个）；本质论=反思（范畴通过对立面映现自身）；概念论=发展（范畴自由地展开自身）。
- **引擎与场域**：生成性（引擎燃烧出场域）与统摄性（扬弃：高级场域把低级场域作为被扬弃的环节收进自身）。
- **介质比喻**：同一引擎在不同介质（水/油/沙/真空）中运转，节奏相同、声音力道不同。

### 3.2 小逻辑·篇级模板（如"第一篇 质"）

- **场域定位**：本篇在所属场域中的功能（1-2 句）
- **三环节总览**：a/b/c 的推进关系（1-2 句 + 可加小表）

### 3.3 小逻辑·环节模板（如"(a) 存在"）

每环节固定五个元素：
1. **文本定位**：§编号 · 德文术语
2. **概念**：范畴的直接规定（2-3 句）
3. **判断**：范畴的自我否定、分裂、暴露其有限性（2-3 句）
4. **推论**：对立在更高层面的统一，成为下一环节的起点（2-3 句）
5. **引擎状态**：本环节在所属场域中的做功方式（过渡/反思/发展）+ 一句介质描述
6. **过渡**：如何进入下一环节（1 句）

（注：本质论环节的判断步强调"成对反思"（同一/差异、原因/结果）；概念论环节强调"自由发展"与逻辑形式的资源。）

### 3.4 现象学·章级模板（如"第四章"）

- **章定位**：本章在意识之旅中的位置与引擎状态（1-2 句）
- **章内结构**：各节总览（表格：节 / 文本形态 / 引擎运转特征）
- **章末过渡**：本章终点如何逼迫进入下一章

### 3.5 现象学·形态模板（如"感性确定性"）

每形态固定五个元素（**引擎诊断替代原知—行诊断**）：
1. **文本对应小节**：§区间
2. **形态界定**：意识在此形态中的"确信"是什么（1 句）
3. **文本内在运动**：3-5 点，按文本环节推进（含关键引文）
4. **引擎诊断**：概念-判断-推论在此形态中如何运转；该形态属于哪种做功方式（过渡/反思/发展）——即引擎在意识介质中的表现
5. **失败与过渡**：此形态为何无法自持 + 如何被迫进入下一形态

### 3.6 表格与引文规范

- 诊断/对照用表格（Markdown 表格 → HTML table）；每表必须有表头与完整数据，不裁剪。
- 引文用引用块（>），标注出处（章/节或 §）。
- 德文术语与中文并列，首次出现加粗。
