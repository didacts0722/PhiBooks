## 整合工作流

1. **定位**：按主题查本索引；未收录的新主题，在 `notes_pheno/ch{n}.json` 的 `gestalten[0].bewegung` 里按环节标题（关键词）定位。
2. **讨论**：在对话中展开讨论（引擎框架、术语纪律：禁「知—行」「正反合」）。
3. **整理**：把讨论要点压缩为 1-4 句，可含 `**加粗**` 与德文术语。
4. **整合**：
   ```
   python integrate_discussion.py <章号> <关键词> "日期|主题|要点..."
   ```
   或直接编辑 `notes_pheno/ch{n}.json`：给对应环节数组追加第 5 个元素（supplements）：
   ```json
   ["环节标题", "p.277", "德文引文", "原解读",
     [{"date": "2026-08-26", "title": "哈姆雷特的延宕", "content": "讨论要点…"}]]
   ```
5. **重建**：`python build_pheno_ch123.py`（自动对拍校验，引文回归检查）。
