# 项目结构（意识层/无意识层/文献层）

> **2026-08-29 定型**：本项目=三层结构——**意识层**（我们写的知识沉淀，git 管理）、**无意识层**（对话原始记录）、**文献层**（输入材料）。工作流（构建/归档/校验）全部建立在此结构上。

## 一、三层结构总览

| 层 | 内容 | 位置 | 大小 | 管理 |
|---|---|---|---|---|
| **意识层** | 笔记/文档/观点/术语/渲染产物 | `项目/`+`docs`+`viewpoints`+`笔记` | ≈12 MB | git（PhiBooks main） |
| **无意识层** | 对话原始记录（zstd）+ 索引 | `对话归档/` | ≈33 MB | git + 独立功能（归档/解压） |
| **文献层** | 本地文献库（输入材料） | `原文/` | ≈3.5 GB | git（大文件——不入 git 或单独处理） |

## 一·五、意识层内部细分（2026-08-29 用户定位）

意识层不是铁板一块——按「思维展开 vs 思维固化」分三层，对应黑格尔 ch6「语言作为精神的定在」：

| 子层 | 内容 | 性质 | 对应 |
|---|---|---|---|
| **说出层** | `项目/<作品>/notes/` | **思维在语言中的展开**——概念链/演绎链可追踪的推演（每步「推出」）；关键点经对话确认展开 | Aussprechen（在场/可复核） |
| **记下层** | `docs/`（大纲/规范/简报）+ `viewpoints/`（观点/术语） | 结论与纪律的固化——大纲/观点/裁定 | Aufschreiben（固定） |
| **产物层** | `笔记/*.html` | 渲染成品（引文对拍） | 成品 |

**notes 的独立价值（用户裁定）**：notes 虽以原文为起点生成，但**不依赖原文存在**——它是在**引擎×文本的思维层面**建立概念链/演绎链，并经**对话确认展开**关键点——具有独立于原文的思维价值。定位=意识层中**接近「说出」而非「记下」**的层面：比无意识层（流动素材）成形，比记下层（固化结论）更活——是思考的进行时被语言固定。

## 三、工作流与结构的对应

1. **构建流**（笔记 → 产物）：`原文/extracted`（文献层）→ `notes_*`（意识层笔记）→ `build_*.py` → `笔记/*.html`（渲染产物）
2. **校验流**：引文对拍（笔记引文 vs 原文）、标签配平、观点库校验、术语主表校验
3. **归档流**（无意识层）：`archive_unconscious.py`（会话 → 对话归档/原始/）→ `decompress_unconscious.py`（zstd → 明文）
4. **观点流**：讨论 → `add_viewpoint.py`（V#/T# 入库）→ views_sync（一致性）
5. **跨轮流**：运行简报（每轮读/写）→ 大纲（核心资产）→ 注释规范（纪律）

## 四、维护纪律

- **新增文件**：意识层放对应目录（notes_*/docs/大纲/viewpoints）；文档优先放 `docs/`，核心资产放 `docs/大纲/`
- **无意识层**：阶段结束 `python archive_unconscious.py`；会话结束 `python decompress_unconscious.py` 转明文
- **文献层**：新增原文进 `原文/<哲学家>/<作品>/`，extracted 由 extract_zeno.py 生成
- **引用路径**：文档中引用 `docs/大纲/...` 等相对路径——移动文件须更新全部引用（参考 2026-08-29 大纲迁移）
