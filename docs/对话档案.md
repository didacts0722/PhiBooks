## 二、已确立的概念体系（含出处）

> **注**：以下概念体系的操作性权威版本已独立为 **`docs/基础观点库.md`**（编号 V1-V12，高度概括，作为笔记摘要指示）与 **`docs/文献观点库.md`**（文本特有观点 T-#，与基础观点互参）。本节保留为对话历史记录。

### 1. 知—行框架（08-21 建立，**2026-08-26 已停用**）

> **状态：已停用。** 2026-08-26 用户裁定：该框架作为原始数据已失去价值，此后不再作为分析工具使用。仅作历史记录保留；`笔记/黑格尔哲学引擎.html` 等历史产物维持原样。

- 知 = 自在存在（Ansichsein）/ 概念 / 理论精神；行 = 自为存在（Fürsichsein）/ 判断（实在化）/ 实践精神；相互推进，统一于绝对知识。
- 黑格尔最推崇的静态命名：**概念（Begriff）与实在性（Realität）**；本质气息上：**无限性**（尚未外化的总体）与**否定性**（外化并返回自身的动力）。
- 现象学各形态：欲望=行抛弃知；主人=知脱离行（空洞寄生）；奴隶=行生产知（劳动塑造自我意识）；斯多葛=知吞噬行；怀疑主义=行异化为纯粹否定；苦恼意识=知行绝对对立。

### 2. 引擎（黑格尔哲学，08-24 建立）
- 「概念-判断-推论」循环链路 = 黑格尔哲学引擎；不同场域拉动不同资源，链路描述随之变化。
- 三大场域：**存在论**（过渡 Übergehen：质/量/尺度）、**本质论**（反思 Reflexion：根据/现象/现实）、**概念论**（发展 Entfaltung：主观概念/客体/理念）。
- 术语校准（用户纠正）：
  - **「正反合」是康德/费希特用语，黑格尔文本基本不用——禁止再用**。
  - 改用：「概念-判断-推论」「自在-自为-自在自为」「否定-扬弃-返回」。
  - **dialektische** = 否定的、彻底怀疑的、动荡的（解构的力）；**spekulative** = 已扬弃的、接受了自身否定整体的肯定结果（重建的力）。二者是功能分工，不是先后步骤。

### 3. 引擎 vs 框架 vs 诊断（08-25 建立）
- **引擎**：自我推进，自己就是自己的运动原因，不需要外部数据；历史是它展开的场域。
- **框架**：来源于对「内容与形式的特定关系」的抽象，需要特定的、具体的、存在于现实中的**原始数据**来启动；**只能处理和原始数据同类型的问题**（普遍性是类型性的，不是无限的）。
- **诊断**（海德格尔式）：对时代生存危机的纠错机制；擅长诊断（技术座架、存在离弃、非本真），但**给不出出路**——缺「肯定性结构运动」类型的原始数据。
- 应用：海德格尔 Ereignis 的原始数据 = 20世纪30年代德意志民族的生存危机（一战战败、技术焦虑、1933 决断）；框架可平移批判现代性，但只能诊断、不能开药方。

### 4. 中国文明：致中和（08-25 晚建立）
- 中国应对生存考验不采取哲学方式（无建基/诊断），而是「**鉴-通-转-配**」操作；最吻合的文本是《中庸》（用户认定）。
- **致中和**：核心不是「中」或「和」，而是「**致**」——未发（中）与已发（和）之间的无间断贯通/转换机制；是**检验程序**（通过结果检验操作是否恰当），不是目标状态。
- **中国思维没有「前提」**（用户纠正助手的西方格义）：直接就在当下执行，合法性在执行之中、不在操作之外的设定；西方思维回溯前提（阿基米德支点），中国思维讲时中/当下。
- 与形式指示对照：海德格尔的形式指示是「诊断之后的路标」（危机中提出的转向标记）；致中和是「诊断之前的地基」（秩序尚存时的操作说明）。技术时代若需重新激活，致中和会「形式指示化」。

### 5. 天命-性-道-教（操作式新解，08-25 晚）
- **天命** = 共同体在断裂时仍有方向（方向感；非命令/命运/神意）。
- **性** = 检验完成后被确认的「刚刚好」（恰当性）；不是本质/本性/nature，性不是起点而是结果。
- **道** = 在检验中走通的具体路径（走通才存在；非普遍原理/法则）。
- **教** = 被保存的、可重新执行的操作记录（存档不是命令；非教义/宗教/教育）。
- 误读总方向：西方逻辑把每个概念读成「内容」（可定义对象）；正确读法是「操作结构中的功能位置」。

### 6. 音乐哲学（08-25 上午，与框架互证）
- 接受：贝多芬第三/五/九、柴六、马勒第二/第六、巴赫部分作品（音乐的奉献）；讨厌：瓦格纳、马勒第三/第九、舒曼舒伯特（抄贝多芬阴郁部分）。
- 判定标准：**结构性运动与共享确认**（第九交响曲：动机发展→逆境吸收转化→个人意识上升到精神）；马勒失败在停留在辩证阶段自我撕裂、未进入思辨的自我回归（「提出了问题，但用更大的声音替代了回答」）。
- 命运 = 连接个人生命与世界的桥梁；行动创造意义，没有共同体就没有一切；器乐代表人之外的存在形态，人声拉近作者意图。
