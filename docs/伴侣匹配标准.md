# 伴侣匹配标准（个人判断工具）

> **来源**：2026-08-29 系列讨论（概念层生存姿态 → 感情分析 → 无孩爱猫女案例 → 最合适伴侣类型反推）。
> **用法**：判断一个人是否合适时，逐条对照；核心看结构（介质/形状/承认），不看标签（职业/身份/外貌）。

## 一、核心公式

**同介质、异形状**——深度与行动力匹配（同介质），领域与节奏不同（异形状），但有交叉对话点。

- 同介质 = 能深聊（自我意识层互认）+ 也在动（精力/行动力匹配）
- 异形状 = 领域/工作/生命节奏不同（不是镜像，有对话空间）
- 交叉对话点 = 运动/音乐/机械等至少一个可共享或尊重的领域

**排除：异介质互补**（生命直接性/需要被接生命层的）——缝合关系=永恒悬空（B/C 90%）。

## 二、五条判断标准

1. **有真劳动（V22 四条件）**：她有一个「不敢不做的对象」（对象持存/自我返回/向对象让步/可承认性）——站着、有形状、不触发拯救欲。
2. **深度可对话**：能接住结构语言（或认真学）——自我意识层互认——您悬空的那层被接住。
3. **也在动的人**：有自己的节奏和推进力（不是静态/拖延/等安排）——两个行动者的关系互相带得动；行动派配静态者=您变成她的发动机（供养/推动=主奴重演）。
4. **生命层自足**：双方都自足——她不靠您接生命层（她有自己的劳动/爱好/朋友），您也不靠她（锻炼/音乐/摩托车=您的出口）。
5. **同介质异形状+交叉对话点**：能深聊但领域不同；运动/音乐至少一个能进入或尊重。

## 三、红线（一票否决）

- **触发主人/拯救欲**：需要被供养/被拯救/被带动的人（「她被需要」≠爱——是项目）
- **异介质互补**：生命层互补型（如无孩爱猫女——她接生命层、您接自我意识层=各自悬空一层）
- **不尊重您的结构**：把您的爱好当「烧钱/浪费时间」（摩托车/一天一练）、要求您放弃自由层出口
- **经济不独立**：指望您的收入全覆盖（您的收入有个人爱好预算——伴侣需独立或接受）

## 四、自检问题（决定前问自己）

1. 我是**接住她**，还是**被她需要**？（前者是关系，后者是项目）
2. 我是想做**关系**，还是想做**改造/启蒙**？（改造欲=坏的无限）
3. 她**不能深聊**，我能接受悬空一层吗？（不能→B/C 90%，及早离开）
4. 关系破裂时，**代价是否对称**？（若她完全依赖您而崩塌=责任≠爱——负担）

## 五、一句话标准

**两个完整的人在相互承认中共同在场**（§260：各自特殊性完全展开、在爱中收回实体统一）——不是缝合两个缺半边的人。她不需要接住您的任何一层（您都自己站着），她只需要接住您这个人——而这是不需要框架的。
